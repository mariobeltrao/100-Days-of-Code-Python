# 🐍 100 Days of Code — Python

Este repositório documenta minha jornada no desafio **100 Days of Code with Python**, no qual pretendo estudar e praticar Python diariamente por meio da construção de **100 projetos ao longo de 100 dias**.

O objetivo deste repositório não é apenas armazenar exercícios, mas registrar minha evolução como desenvolvedor, acompanhar meu progresso e transformar os conhecimentos adquiridos durante o curso em projetos práticos.

## 🎯 Objetivos do desafio

Durante os 100 dias, pretendo desenvolver uma base cada vez mais sólida em Python, passando dos fundamentos da linguagem até assuntos e ferramentas mais avançadas.

Ao longo da jornada, estudarei e praticarei conceitos relacionados a:

* Fundamentos da programação com Python
* Lógica de programação e resolução de problemas
* Programação Orientada a Objetos
* Automação de tarefas
* Desenvolvimento de jogos
* Desenvolvimento de aplicações desktop e interfaces gráficas
* Desenvolvimento Web
* APIs e requisições HTTP
* Web Scraping
* Manipulação e análise de dados
* Data Science
* Introdução a Machine Learning
* Visualização de dados
* Construção de projetos completos

Também terei contato com tecnologias e bibliotecas como:

`Flask` • `Requests` • `Beautiful Soup` • `Selenium` • `Pandas` • `NumPy` • `Matplotlib` • `Plotly` • `Scikit-Learn`

## 🚀 Objetivos a longo prazo

Este desafio faz parte de um objetivo maior de construir uma base sólida em Ciência da Computação e desenvolvimento de software.

Ao longo dos próximos anos, quero:

* 🧠 Fortalecer minha lógica de programação e minha capacidade de resolver problemas.
* 🐍 Alcançar um bom domínio da linguagem Python.
* 💻 Evoluir como desenvolvedor e aprofundar meus conhecimentos em desenvolvimento de software.
* 🌐 Aprender cada vez mais sobre desenvolvimento Back-End e Full Stack.
* 🗄️ Desenvolver conhecimentos em bancos de dados, APIs e arquitetura de aplicações.
* 📊 Explorar áreas como análise de dados, Data Science e Machine Learning.
* 🛠️ Transformar conhecimentos teóricos em projetos reais.
* 📚 Aplicar na prática conceitos estudados durante minha formação em Ciência da Computação.
* 📁 Construir um portfólio consistente de projetos no GitHub.
* 🎯 Me preparar para futuras oportunidades profissionais, estágios e projetos na área de tecnologia.
* 📈 Manter uma rotina de aprendizado contínuo e acompanhar minha evolução ao longo do tempo.
